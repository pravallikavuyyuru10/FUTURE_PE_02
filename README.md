# ClearGlow Skincare UGC Ad Content Pack

## Overview

This project is an AI-generated User-Generated Content (UGC) advertising content pack created for **ClearGlow Skincare Kit**, a skincare product designed for teenagers with acne-prone, dry, and sensitive skin.

The goal of this project is to demonstrate how AI tools can be used to create engaging, platform-specific marketing content for modern social media campaigns.

---

## Project Objective

Develop authentic and relatable UGC-style advertising content that:

* Captures audience attention within the first few seconds
* Addresses common skincare concerns among teenagers
* Builds trust through relatable storytelling
* Encourages engagement and conversions through effective CTAs
